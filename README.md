# A-simple-web-application-that-scrapes-product-data-from-an-e-commerce-website-
A simple web application that scrapes product data from an e-commerce website (&lt;https://books.toscrape.com/>, a site built for scraping practice). The user picks a product category from a dropdown, and the scraped products are shown in a readable HTML table (title, price, rating, availability and a link).
